# 森系自然风（Cottagecore）微缩工作室 v2.0 —— 原创设计清单

> 本清单为完全原创设计，仅保留"展示盒式两面墙开放"布局，所有元素均脱离参考图。用于生成独立2D素材组件 → 3D建模。
> 坐标系：房间地板左下角为原点 (0,0,0)，1 单元 ≈ 10cm。

## 原创设计核心替换

| 原参考图痕迹 | 原创替换 | 理由 |
|-------------|---------|------|
| 粉色卡比玩偶 | **一只蜷缩的小鹿**（奶油色+白斑，森林系原创IP） | 卡比是任天堂IP，必须替换 |
| 显示器动漫女孩 | **显示器显示森林代码界面**（深色背景+绿色代码+树叶装饰边框） | 原创画面，体现创作者身份 |
| 白色电子琴 | **一把原木色小吉他**（靠在右墙，琴身有藤蔓刻纹） | 更自然、更独特 |
| 小熊玩偶 | **蘑菇精灵玩偶**（圆脑袋带蘑菇帽，坐姿） | 原创森林角色 |
| 鱼缸小鱼 | **水晶雪花球**（玻璃球内有微缩小树和飘雪） | 更有手作感，不抄袭 |
| 粉色抽屉柜 | **树桩抽屉柜**（仿树桩造型，三个抽屉像年轮切面） | 彻底脱离参考图配色和造型 |
| 小蘑菇台灯 | **松果造型台灯**（松果底座+亚麻灯罩，暖黄光） | 自然元素，原创 |
| 彩色三角旗 | **干花与叶子装饰串**（干薰衣草+尤加利叶+小松果串联） | 比彩旗更森系、更成熟 |
| 底座水面 | **苔藓岩石地台**（真实苔藓+灰岩+地衣，无水面） | 森林地面感，不再抄袭水面底座 |
| 马克杯 | **树皮纹理陶杯**（仿树皮凹凸质感，带木柄） | 原创造型 |
